# Atlas 首页 Banner 优化

## 范围与依据

- 默认 Atlas 首页改用图片横幅；classic、vault 和 Atlas 列表模式保持现有实现。
- 修改前已核对 Atlas Home、classic Home、VaultBannerHero 和 useBannerCarousel 的布局、链接、API 与生命周期写法。
- 公共 `home_hero` 接口已按有效期、启用状态过滤，按 `sort_order DESC, created_at DESC` 排序；返回结果不含排序字段，前端保留 API 顺序，最多采用 5 张有效横幅。
- 原有未提交文件均保留；从最新 fork main `40b0431a` 创建 `kano/atlas-home-banner`。

## 实现

- AtlasBannerHero 承接读取、跳转、图片失败与轮播；桌面容器宽 1120px，背景比例 8:3，左侧 6% 处显示最多两行文案和胶囊订阅按钮。
- 小于 768px 时不创建图片元素，也不预加载背景；使用当前主题颜色。视口变化由 matchMedia 监听。
- 每 5 秒切换、180ms 淡入淡出；控制区仅提供指示按钮，触控区至少 44px。悬停、焦点、隐藏、减少动画分别记录，全部解除后才恢复播放。减少动画仅手动切换。
- 计时器和三个环境监听器在卸载时清理；迟到的 API 响应不会重新启动计时。图片失败仅影响对应 URL，文案与链接仍可使用。
- 未增加公共 API、数据库字段或后台设置。素材及制作提示见 `assets/atlas/README.md`。

## 圆角补充

用户反馈首页 Banner 图片缺少圆角。核对 AtlasPlanCard 的 10px 卡片圆角、AtlasProductListItem 的图片圆角和 VaultBannerHero 的容器裁切模式后，在 Atlas Banner 舞台容器添加 10px 圆角；现有 overflow-hidden 会同时裁切图片及轮播过渡中的两张横幅。继续沿用当前 PR，未碰原有未提交文件。

本次只改视觉样式，不新增重复实现的测试。现有组件 10 项测试与 80% 覆盖率门槛通过，类型检查和生产构建通过，diff 检查通过。浏览器确认四角均为 10px 且 overflow 为 hidden；桌面截图裁切正常，390px 手机仍没有背景图片元素或请求。最新 CI 结果以 PR 检查区为准。

## 轮播控制精简

保留每 5 秒自动轮播、悬停/焦点/页面隐藏暂停及减少动画模式。组件交互测试改用指示按钮，补充控制区只有三个按钮、当前项更新及点击重置自动轮播间隔的验证。继续更新 PR #7，原有未提交工作保留，生产发布等待明确指令。
